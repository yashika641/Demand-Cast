📌 DemandCast – Platform Overview & Purpose

DemandCast is an AI-powered Demand & Supply Analytics Platform that provides end-to-end insights for businesses by analyzing their sales, inventory, product, customer, pricing, and supply chain data. The platform is built to make advanced demand forecasting, lead time prediction, stockout analytics, price elasticity modeling, promotional effectiveness measurement, and retrieval-augmented advisory accessible to every business user — without requiring technical expertise.

DemandCast serves as a unified workspace where users can upload their raw business files, trigger automated model training pipelines, visualize predictions, explore insights, and receive intelligent recommendations through an AI chatbot trained specifically on demand-supply analytics.

🎯 What DemandCast Does
1. Data Upload & Intelligent Processing

Users can upload simple CSV or Excel files:

Sales transactions

Inventory balance

Product master

Supplier lead time

Promotional pricing history

Pricing and discount files

Customer-level purchases

DemandCast automatically:

Identifies the file type using intelligent regex and column mapping

Cleans and standardizes the data

Creates missing tables such as a synthetic product master when needed

Validates uploaded files

Handles missing values and inconsistent schemas

This ensures users do not struggle with formatting challenges.

Once the user starts the training:

All pipelines run in the background using Redis + RQ

Each model writes logs, metrics, and artifacts for future predictions.

⚙️ 8. Technical Architecture

DemandCast uses:

FastAPI backend

Supabase for authentication & file storage

Redis + RQ for background jobs

MLflow for model registry

Scikit-learn, XGBoost, LightGBM, and Keras for ML

React for frontend

Tailwind for UI styling

RAG with vector embeddings for intelligent advisory

The entire system is modular, scalable, and designed for enterprise use.
